# Исходники значков

Один квадратный PNG на приложение, **1024×1024**, с готовым фоном и
скруглением: плитка и есть значок, подложку оболочка под него не рисует.

Имя файла — идентификатор значка из реестра `Platinum/Apps.qml`, поле `icon`.
Например `app-settings.png` для записи `icon: "app-settings"`.

Размеры под экраны генерируются командой:

```sh
platinum/shell/tools/make-icons.sh            # все
platinum/shell/tools/make-icons.sh calendar   # только названные
```

Она кладёт в `homescreen/icons/` три файла: `<имя>.png` (128 px),
`<имя>@2x.png` (256) и `<имя>@3x.png` (384). Суффиксы подставляет сам Qt по
плотности экрана — как в iOS; в QML остаётся один путь без суффикса.

Пока значок не перерисован, оболочка берёт старый `.svg` из `homescreen/icons/`.
